Здесь живет типизированный клиент для обращения к вашему бэкенду.

Зачем: Вместо того чтобы в каждом React-компоненте вручную писать fetch('/api/v1/estimates') и описывать типы ответа, фронтенд импортирует готовый метод: api.estimates.create(data). Он уже знает URL, формат ответа (благодаря shared-types) и как обрабатывать ошибки.

Пример: Обертка над fetch или Axios, которая автоматически подставляет JWT-токен (сессию) в заголовки запросов.
