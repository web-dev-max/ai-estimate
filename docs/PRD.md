# PRD — AI-сметчик для мастеров РФ (MVP)

## Продукт
SaaS-помощник для частных мастеров и бригад: превращает описание заказа в профессиональную смету с работами и материалами за минуты.

## Каналы
- Telegram Bot
- MAX Bot
- React Mini App (внутри мессенджеров и в браузере)

## Аудитория
Частные мастера, специалисты, бригады. Категории: ремонт и отделка, сантехника, электрика, строительство, мебель, клининг, грузовые услуги, благоустройство, автоуслуги, прочие.

## Ключевые сценарии
1. **Смета из текста**: мастер пишет заказ → AI извлекает работы/объёмы → уточняющие вопросы → подбор цен → смета → редактирование в Mini App → PDF.
2. **Смета по фото** (следующий этап): AI предлагает работы, количественные параметры подтверждает мастер.
3. **Индивидуальный прайс**: загрузка Excel или ручное добавление расценок; дальнейшие сметы учитывают личный прайс.

## Функциональные блоки
- Боты: `/start`, создание сметы, «Мои сметы», «Мой прайс», профиль, тариф, помощь. Кнопки, уточнения, PDF, контекст диалога.
- Mini App: главная, создание, редактор, каталог, мой прайс, история, просмотр, профиль, подписка.
- AI-модуль: классификация интента, извлечение данных, вопросы, матчинг каталога, структурированный ответ.
- Движок расчёта: работы, материалы, коэффициенты, скидки, итог, округление.
- PDF: реквизиты, позиции, материалы, итог, срок действия.
- Админка: пользователи, категории, услуги, цены, импорт Excel, AI-лимиты, подписки, аналитика.

## Границы MVP (не делаем)
Сложные чертежи, полноценная CRM, зарплаты сотрудников, автосбор цен из десятков источников, сложная аналитика, голос, распознавание материалов по фото, мобильные приложения App Store/Google Play.

## Нефункциональные цели
- Ответ без AI: до 500 мс.
- Смета с AI: цель до 20 с.
- Доступность: цель 99,5%.
- Валюта: RUB. Язык: русский. Часовые пояса РФ.
- Файлы: S3-совместимое хранилище. Логи структурированные. Бэкапы ежедневные.
- Мониторинг: Sentry. Доступ: RBAC.

## Безопасность и комплаенс

- DeepSeek API Key не попадает на frontend.
- Webhook защищены от подделки и повторов.
- Проверка принадлежности сметы пользователю.
- Ограничение размера файлов и rate limit.
- 152-ФЗ: согласие на обработку, локализация БД, передача данных внешнему AI-провайдеру — проверить до публичного запуска.
