# Roadmap MVP

Правило: один этап — один набор задач для агента. Не переходить к следующему, пока не выполнены критерии приёмки этапа.

## Этап 1. Фундамент (2–3 дня)
- pnpm workspace, NestJS + React, PostgreSQL + Prisma, Docker Compose.
- ESLint + Prettier, Swagger, CI/CD.
- **Готово, когда:** `docker compose up` поднимает БД и backend, `pnpm lint && pnpm typecheck` проходят, Swagger доступен.

## Этап 2. Пользователи и каталог (4–6 дней)
- Авторизация, Telegram/MAX идентификаторы, профили.
- Категории, услуги, единицы, системные и личные прайсы, регионы.
- **Готово, когда:** можно создать пользователя, привязать мессенджер, получить категории/услуги/прайс через API; есть тесты.

## Этап 3. AI-движок (5–8 дней)
- DeepSeekProvider, промпты, JSON-извлечение, вопросы, матчинг, валидация, состояние диалога.
- **Готово, когда:** на тестовых запросах возвращается валидный `EstimateExtraction`, нет неподтверждённых цен, есть логи `ai_requests`.

## Этап 4. Движок смет (4–6 дней)
- Расчёт работ/материалов, коэффициенты, скидки, ручное редактирование, история, пересчёт.
- **Готово, когда:** decimal-расчёты, unit-тесты на округление/границы/отрицательные значения; AI не участвует в арифметике.

## Этап 5. Мессенджеры (4–6 дней)
- Telegram Bot, MAX Bot, webhook, кнопки, PDF, обработка ошибок и повторов.
- **Готово, когда:** оба адаптера реализуют общий интерфейс, webhook защищены, PDF отправляется.

## Этап 6. React Mini App (6–9 дней)
- Главная, создание, редактор, каталог, мой прайс, история, профиль.
- **Готово, когда:** смету можно создать и отредактировать, интерфейс адаптивен, авторизация через платформу работает.

## Этап 7. PDF и админка (4–6 дней)
- PDF с кириллицей, админпанель, каталог, импорт Excel, управление ценами.
- **Готово, когда:** PDF корректен, импорт Excel валидирует колонки/услуги/единицы/дубли/цены.

## Этап 8. Тестирование и запуск (4–6 дней)
- Unit/integration/E2E, безопасность, стоимость AI, деплой, закрытое тестирование.
- **Готово, когда:** чек-лист `docs/ACCEPTANCE.md` выполнен.

## Порядок реализации (рекомендация)
1. Backend + каталог + прайсы + расчётный движок.
2. DeepSeek + Telegram.
3. Проверка бизнес-логики.
4. MAX + React Mini App.

- Закрыть вопросы 152-ФЗ и передачи данных внешнему AI-провайдеру.
