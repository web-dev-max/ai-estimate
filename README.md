# AI-сметчик

Monorepo SaaS «AI-сметчик для мастеров РФ». Стек и структура — в `docs/ARCHITECTURE.md`.

## Требования

- Node.js 22+
- pnpm 12.6.0 (`packageManager` в корневом `package.json`)

## Команды

```bash
pnpm install
pnpm dev
pnpm build
pnpm lint
pnpm typecheck
pnpm test
pnpm format
```

Скопируйте `.env.example` в `.env` и заполните значения локально
